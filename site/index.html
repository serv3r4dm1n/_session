Session command

Paste into an interactive Bash or Zsh shell. The command contains a one-time session key; treat it as sensitive. It changes only the target application's service settings, stays in the foreground, and restores the previous settings when stopped with Ctrl+C.

How it works

  1. Start the Secure session workflow in GitHub Actions.
  2. Open the session link from the workflow run summary.
  3. Enter the passphrase and copy the decrypted command.
  4. Run it on the remote machine and keep the workflow active while the session is in use.

This page is static. It is not redeployed for each session; the browser and the waiting runner communicate through an encrypted relay channel.

Cancel the workflow to end the session. Starting a new run replaces the previous session.
